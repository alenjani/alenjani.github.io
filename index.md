# Ali Lenjani

**Lead ML / Recsys & Personalization** — Stanford & NASA postdoc, Purdue PhD.

I build production recommender systems and personalization platforms at scale —

## What I do

- **Production recommender systems** — two-tower architectures, HNSW vector search, real-time retrieval at sub-10ms latency.
- **LLM evaluation & quality gating** — multi-dimensional "human-proxy" judging pipelines using Chain-of-Thought reasoning.
- **Counterfactual offline simulation** — high-fidelity sim platforms with LLM agents to minimize sim-to-real gap before deployment.
- **Computer vision for industry** — multi-class object detection, edge deployment, leakage-safe data pipelines.
- **Digital twins & risk-informed simulation** — physics-informed models, Monte Carlo trade studies (NASA Space Habitat platform).

## Selected impact

- **Two-tower recsys for 15M+ users** trained on 1.5B+ interactions; sub-10ms retrieval over 500k+ items in Azure AI Search (HNSW).
- **3–5× inference speedup** on the User Tower via ONNX Runtime over native PyTorch.
- **Bi-weekly warm-start training strategy** that cut compute costs by 5× on 8× A100s using MosaicML Streaming.
- **Ranking-aware contrastive loss** combining InfoNCE with same-taxonomy hard-negative mining for fine-grained attribute discrimination.
- **LLM-as-judge platform** scoring 7 orthogonal latent dimensions to automate quality gating for recsys releases.
