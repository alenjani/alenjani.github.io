Selected work

End-to-End Real-Time Recommendation Platform — Fortune 50 retailer (15M+ users)2022 — Present

  • Built and productionized a latency-critical two-tower recsys serving 15M+ active users, trained on 1.5B+ interactions.
  • Designed a sub-10ms retrieval pipeline indexing 500K+ items in Azure AI Search (HNSW). Optimized User Tower inference with ONNX Runtime for a 3–5× speedup over native PyTorch.
  • Designed a Ranking-Aware Contrastive Loss combining InfoNCE with same-taxonomy hard-negative mining to force fine-grained attribute discrimination.
  • Solved data bottlenecks with MosaicML Streaming for sharded reads across 8× A100s. A bi-weekly warm-start training strategy cut compute cost by 5×.

LLM-as-a-Judge for Recommendation Systems

  • Designed and shipped a multi-dimensional evaluation platform that quantifies semantic complementarity for recsys outputs.
  • Engineered a declarative "Human-Proxy" judging pipeline scoring 7 orthogonal latent dimensions via Chain-of-Thought reasoning to automate quality gating before release.

Counterfactual Offline Simulation Platform

  • Built a high-fidelity offline simulator integrated with LLM agents for autonomous user behavior.
  • Features include "time-travel" historical sampling and self-adaptive metric tuning to minimize the sim-to-real gap for production deployment decisions.

Vision AI for Manufacturing Quality Control

  • Architected an end-to-end computer vision inspection framework across multiple CTQ checkpoints for automated defect detection and station health monitoring.
  • Trained multi-class object detection models in PyTorch; engineered operational decision logic and inference thresholds to minimize false positives in high-throughput environments.
  • Built a leakage-safe data workflow on GCP/GCS + Label Studio, overcoming physical manufacturing constraints (lighting, misalignment, class imbalance) with targeted hard-negative mining.
